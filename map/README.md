# Flag Football Investment Map

Interactive US map showing youth flag football leagues and discovered club locations.
Loads data from `clubs.json` (generated by the pipeline).

## Files

```
map/
  map.html    — entry point; links styles.css and app.js
  app.js      — all application logic; fetches clubs.json at runtime
  styles.css  — all styles; zero org data embedded
  README.md   — this file

clubs.json    — data file (generated by pipeline/); must be at project root
```

## Running locally

**Important:** `map.html` fetches `../clubs.json` via the Fetch API. Browsers block
`fetch()` on `file://` URLs (CORS). You must serve the project from a local HTTP
server:

```bash
# From the project root (one level above map/):
python -m http.server 8080
```

Then open: **http://localhost:8080/map/map.html**

## Deploying to GitHub Pages

1. Push the repository (including `clubs.json`) to GitHub.
2. In repo Settings → Pages, set source to the `main` branch, root `/`.
3. The map will be at `https://<user>.github.io/<repo>/map/map.html`

`clubs.json` must be committed to the repo for Pages to serve it. Re-run the
pipeline locally, commit the updated `clubs.json`, and push to refresh data.

## Features

- **Choropleth map** — states shaded by number of leagues + discovered clubs
- **National Operators** button — lists all national operators (i9 Sports, RCX/NFL FLAG, Skyhawks, etc.) with full investor detail
- **Multi-State Operators** button — lists operators spanning multiple states with unspecified coverage
- **State click** — right panel shows leagues + any discovered clubs in that state
- **Club pins** — gold dots on the map for geocoded club locations; click for detail
- **Two-tier panel** — clubs section (orange border) above leagues section, clearly labeled; a club's detail view shows its parent league's investor data separately
- **Disclaimer footer** — every detail panel notes that revenues are modelled estimates

## Data contract

The map reads exactly one file: `clubs.json`. Its schema is documented in
`pipeline/README.md`. To add data, run the pipeline and replace `clubs.json`.
The map contains **zero hardcoded org data**.

## Honesty

`null` values render as blank or "Not available." Revenue figures come from the
`Revenue_Notes` column of the original CSV and are modelled estimates — this is
stated on every panel. Clubs listed are only those found by the pipeline on real
publicly accessible pages.
